没有 worker 在岗怎么办？

1. 确认 A 已按上面的 MCP 配置连上，并且在循环调用 service_wait；
2. 若 A 报工具超时，把 config.yaml 里的 queue.wait_timeout_s 调到 20~25 秒；
3. 想先不接 A 直接验证链路，运行 examples\demo_agent_a.py（模拟 A）。
4. 没 worker 时软件会收到 503 no_worker，属于预期保护。
